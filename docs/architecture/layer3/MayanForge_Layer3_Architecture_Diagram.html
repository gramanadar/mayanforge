1 · System architecture and trust boundaries

Three logical planes inside one modular Layer 3. The Orchestrator is the only workflow authority; the Harness reaches the outside world only through the Tool Gateway; quality verdicts come from an independent engine; every human decision arrives as a signal from Layer 2.

2 · Six SDLC stages, gates and repair

A stage advances only when its mandatory gates PASS and its human approvals are recorded. Purple borders mark human gates. Repair never starts on its own.

3 · Draft generation: Architecture example

Layer 3 writes every draft; Layer 2 asks for it, stores it, and lets people select, edit and approve. The same shape applies to intake, requirements, build plan, verification plan, change impact and release notes (section 8).

4 · Build: plan, mandatory review and integration

No agent starts before a person approves the plan and starts the build; no task output is merged — or unblocks its dependents — before a person reviews it.

6 · State machines

Four separate state models. The Watchdog state is a projection beside the workflow, never a second authority.

Workflow (build and verify) · generation workflows are single-task: ADMITTED → RUNNING → COMPLETED with StageOutputProduced

RECEIVED→ADMITTED→PLANNING→WAITING_PLAN_APPROVAL→READY→RUNNING→INTEGRATING→CANDIDATE_FROZEN→WAITING_TEST_PLAN_APPROVAL→VERIFYING→WAITING_SIGNOFF→COMPLETED
alternates: BLOCKED_APPROVALRETRY_WAITREPAIR_REQUIRED (waits for a person)FAILEDCANCELLED

Task (DAG node) · READY only when every predecessor is SUCCEEDED (reviewed and merged)

PENDING→READY→LEASED→RUNNING→OUTPUT_VALIDATION→AWAITING_REVIEW→MERGING→SUCCEEDED
alternates: RETRY_WAITCHANGES_REQUESTED → READYBLOCKEDFAILED (person may retry)CANCELLED

Harness attempt · pins task, role, skill-lock, policy, context digests, sandbox profile and budget

CREATED→ADMITTED→PREPARING→READY→RUNNING→CHECKPOINTING→VALIDATING→COMPLETED
exceptions: WAITING_APPROVALSTALLEDRETRYABLE_FAILURETERMINAL_FAILURECANCELLED

Watchdog monitoring · every human wait is HEALTHY; STALLED / ESCALATED are sent to Layer 2

HEALTHY→SUSPECT→STALLED→RECOVERING→HEALTHY
or ESCALATED — stays stopped until a person cancels or authorizes recovery
