1 · Component architecture

One Spring Boot deployable with seventeen bounded modules. Layer 2 owns business records, drafts, human decisions and read models; it never runs agents, tools or tests.

2 · Draft generation: Layer 2 asks, Layer 3 writes

Every stage has a named generate command. Layer 2 checks the approved inputs and budget, Layer 3 writes the draft, and Layer 2 stores it for people to select, edit and approve. Layer 2 never calls an LLM.
